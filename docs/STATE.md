## Следующий шаг

После интеграции проверь сборку, replay и изоляцию на свежем checkout. Используй новый ID серии при каждом dry-run.

```sh
npm run build
docker build -f tools/runner/Dockerfile -t frugal-runner:local .
node_modules/.bin/frugal run --mode paired --feature add-transfer-limits --dry-run --series integration-dry-run --image frugal-runner:local
node scripts/replay.mjs bench/runs
node_modules/.bin/frugal report bench/runs --out report
```

Ф0 требует два принятых автономных B0 из двух на M-M. Для следующей когорты выбрана `opencode-go/kimi-k2.7-code` на той же фиче и с замороженным B0. Перед двумя последовательными прогонами нужны Docker dry-run, живой smoke этой модели и сверка доступной квоты.
